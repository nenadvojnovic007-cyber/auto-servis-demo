# MotorLab auto-servis demo

Demonstracioni, statički sajt za prezentaciju mogućeg izgleda i funkcionalnosti sajta nezavisnog auto-servisa. MotorLab je fiktivan naziv. Kontakt podaci, radno vreme, usluge i vizuali služe isključivo kao primer i menjaju se proverenim podacima konkretnog klijenta.

## Struktura

- `index.html` — semantička struktura i sadržaj
- `css/style.css` — osnovni dizajn
- `css/responsive.css` — responzivna prilagođavanja
- `js/main.js` — mobilni meni, FAQ i demo validacija forme
- `assets/` — slike, ikone i fontovi
- `netlify.toml` — podešavanje objave i bezbednosnih zaglavlja

## Lokalni pregled

Pokrenuti statički server iz korena projekta, na primer:

```bash
python -m http.server 8000
```

Zatim otvoriti `http://localhost:8000`.

## Prilagođavanje klijentu

Pre objave zameniti fiktivan naziv, opis, usluge, radno vreme, kontakt podatke, adresu i fotografije. Sve poslovne tvrdnje mora da potvrdi klijent. Demo forma trenutno ne šalje i ne čuva podatke.

## Fotografija

Hero fotografija je namenski generisan demo vizual za ovaj projekat. Na sajtu je jasno označena kao demonstracioni sadržaj i ne predstavlja stvarni rad servisa.
